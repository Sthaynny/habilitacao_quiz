- **Um repositório**, dois binários: **Habilitação Quiz** (grátis, limites) e **Habilitação Quiz+** (pago).
- **AdMob → promo do próprio Quiz+** nos mesmos slots (sem rede de terceiros).
- **Histórico:** o app **já guarda só os últimos 10** questionários (`HistoricoEntity`); Free mantém; **+** ilimitado.
- **Roadmap:** Onda 1 gate/promo → Onda 2 histórico rico → Onda 3 Aprender → Onda 4 IA.
