# Placas de advertência (Pro)

Placas de **advertência** alertam sobre **condição ou risco na via**. Padrão MBST: fundo **amarelo**, símbolo **preto**, formato em geral **quadrado** com vértice para cima (losango implícito na família de advertência).

## O que muda na condução

- **Não proíbe** por si só (salvo combinação com placa de velocidade).
- Exige **reduzir velocidade**, **aumentar atenção** e preparar manobra segura.

## Exemplos frequentes na prova

| Código (família A-) | Risco |
| :--- | :--- |
| **Curva acentuada** (à direita/esquerda) | Reduzir antes da curva; não ultrapassar sem visibilidade. |
| **Série de curvas** | Manter velocidade compatível por vários trechos. |
| **Animais** | Possível presença de animais na pista (rural). |
| **Obras** | Operários, máquinas, pista irregular. |
| **Pista escorregadia** | Chuva, óleo ou pavimento liso — distância maior. |
| **Crianças** | Proximidade de escola ou área de recreação. |
| **Cruzamento de pedestres** | Atenção redobrada; pode haver faixa próxima. |
| **Estreitamento de pista** | Ajustar posição e velocidade. |

## Advertência × regulamentação

- **Amarela** = “cuidado, algo perigoso **pode** acontecer”.
- **Vermelha/azul regulamentar** = “você **deve** ou **não pode**”.
